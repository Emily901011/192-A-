# OB Quest — COMM 192 practice game

A phone-friendly practice game for UBC Sauder COMM 192 (Organizational Behaviour).

**Play:** https://emily901011.github.io/192-A-/

- Covers the midterm (Classes 1–10): Daily Run with spaced repetition, a class path, Term Sprint and a Midterm Boss.
- Progress is saved in your own browser (nothing is uploaded).

Unofficial, student-made practice. Not from or endorsed by the instructor or the course team. If anything here disagrees with the slides, Canvas or the instructor, they are right.
